# Rails workflow router

Read AGENTS.md and its Rails Engineer Profile first. Workflow: sdd may use the optional sdd-* skills
and specify/ seed; run sdd-init only after the user elects to install that seed into their project.
Workflow: conventional uses the team's existing issue, branch, test, and review process, with
implementation-workflow as the rich-models reference when applicable. Neither route creates project
files without user confirmation.
