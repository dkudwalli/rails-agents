# Rails models router

Read AGENTS.md and its Rails Engineer Profile first. A layered profile uses layered-model-patterns,
rails-concern, query-patterns, and service-patterns as appropriate. A rich-models profile uses
rich-models-model-patterns, concern-patterns, and state-records. Use the profile's architecture
rather than adopting a pattern from the other set.
